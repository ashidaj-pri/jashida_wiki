Migration Hub
==================================

---------------------------------
概要
---------------------------------

- サーバやアプリケーションの移行を管理するためのサービスで、移行の進捗状況を管理するのが主な機能
- AWS Migration HUB単独で使うというよりは各種ツールと連携して移行状況を管理するサービス
- AWS Migration HUBは大きく次のフェーズに分けて遷移する

  - フェーズ 1: 検出
  - フェーズ 2: 移行
  - フェーズ 3: 追跡

---------------------------------
構成
---------------------------------

- フェーズ 1: 検出

  - 「検出」のフェーズで使用できるAWS移行ツールが以下の通り

    .. list-table::
       :header-rows: 1
       :widths: 40 60

       * - サービス名
         - 概要
       * - Application Discovery Service Agentless Collector
         - 物理サーバ、VMにエージェントレスでデプロイして情報収集するツール
       * - AWS Discovery Agent
         - 物理サーバ、VMにエージェントでデプロイして情報収集するツール。実行中のプロセスやネットワーク情報も収集可能
       * - Migration Evaluator
         - サーバーリストの作成や、AWSクラウドでオンプレミスワークロードを実行することによる予測コスト見積もりが可能。

- フェーズ 2: 移行
  - 「移行」のフェーズで使用できるAWS移行ツールが以下の通り

    .. list-table::
       :header-rows: 1
       :widths: 40 60

       * - サービス名
         - 概要
       * - Application Migration Service (MGN)
         - 物理、仮想等の各種サーバをクラウドへ移行するツール
       * - Database Migration Service (AWS DMS)
         - データベースを移行するツール

- フェーズ 3: 追跡
    - AWS Migration HUBのダッシュボードから移行を開始し、ステータスを確認していくことが可能
