PrivateLink¶

概要¶

  • インターネットを経由せずに、クラウド上の仮想ネットワーク（VPC）と各種サービスを安全にプライベート接続する仕組み

  • 以下の2つがセットとなり、AWS PrivateLinkが提供されている。

    • VPCエンドポイント（サービス利用側のVPC内で作成）

    • VPCエンドポイントサービス（サービス提供側のVPC内で作成）

構成¶

  • サービス利用側
    • VPCエンドポイント

      • インターフェイスエンドポイント（一部のAWSサービスやNLBを介した独自サービスなどが対象）

      • Gateway Load Balancerエンドポイント

      • ゲートウェイエンドポイント（S3およびDynamoDB）**

    • VPCエンドポイントサービス

**ゲートウェイエンドポイントの場合はVPCエンドポイントサービスは作成されない

特徴¶

VPC Peering = ネットワーク同士をつなぐ PrivateLink = サービスへの専用入口を作る
